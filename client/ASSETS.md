# voxel · 立方世界 · 素材清单

本清单描述**已经入库**的素材（`client/assets/`），不是计划。
总量：**位图 19 张 + 音效 7 个 = 688 KB**（口径 0.3~1.5 MB）。

全部素材为本项目自制：AI 生成后经 `client/tools/make_assets.py` 抠底/裁边/缩放
入库，或由该脚本程序化合成。**不含任何第三方素材**（早期版本提到过的
MineClone2 / VoxeLibre 只作玩法参考，仓库里没有它的任何文件，也没有 `LEGAL.md`
待核对的复制链——本次交付不使用它）。

### 1.5 皮肤包（1 个 CSS）

`skins/voxel/skin.css`：矿洞风（石灰岩灰 + 铜绿 + 矿灯橙）。构建时拷到
`build/voxel/skins/voxel/`（exe 同级），启动时 `host.App().UseSkin("voxel")`
应用（必须在 `UseSkin("dark")` 之后）。控件基线 `base.css` **不拷**——zanc 会

`client/src/VoxelPalette.zan` 一一对应。

## 二、朝向帧（`player_sheet.png`）

引擎运行时转不了图——`Canvas.BlitImage` 只有源矩形 `(sx,sy,sw,sh)`，没有旋转、
没有水平翻转。所以方向只能**离线预烘焙**：程序化水平镜像一次，存成两帧精灵表。

| 项 | 值 |
|---|---|
| 精灵表尺寸 | 192×128（两帧，每帧 96×128） |
| 单帧显示尺寸 | 48×64（入库按显示尺寸的 2 倍） |
| **帧索引 0** | 原图 = **朝右**（源矩形 `(0, 0, 96, 128)`） |
| **帧索引 1** | 水平镜像 = **朝左**（源矩形 `(96, 0, 96, 128)`） |

映射规则写在 `client/src/VoxelFacing.zan`（纯函数，不碰画布）：

```
逻辑朝向 → 屏幕朝向：+x(East)/-z(North) = 朝右；-x(West)/+z(South) = 朝左
屏幕朝向 → 取帧索引：Frame(true) = 0（朝右），Frame(false) = 1（朝左）
取帧源矩形：SrcX(facingRight) = Frame(facingRight) * 96   ← 源图像素
```

断言用例（`client/tests/voxel_test.zan` 的 `TestFacing`）按这套映射钉住：左右
两帧索引不同、源矩形不同、向左走（`FacingForStep(-1,0)`）后 `FacingRight` 变
false 且取到的帧索引改变。

**等距里"朝右/朝左"是屏幕方向，不是网格方向**：+x 在屏幕右下、−x 在左上、
+z 在左下、−z 在右上。所以逻辑上"往 +z 走"也要取朝左那一帧。

## 三、音效（7 个）

全部 `client/assets/sfx/*.wav`，格式 **22050 Hz / 16 bit / 单声道**，
由 `make_assets.py` 用 Python 合成（不经图像 API）。

| 文件 | 时长 | 触发时机 | 合成手法 |
|---|---|---|---|
| `step.wav` | 0.09 s | 玩家走了一格 | 噪声 × 指数衰减（软脚步） |
| `place.wav` | 0.16 s | 放置方块成功 | 150 Hz 正弦 + 极短噪声咔哒 |
| `break.wav` | 0.26 s | 破坏方块成功 | 低通噪声（砂砾）+ 90 Hz 低音 |
| `error.wav` | 0.22 s | 放置/破坏被拒（没材料、格子被占、越界） | 方波交替（150/104 Hz）蜂鸣 |
| `complete.wav` | 0.50 s | 一张图纸建成、解锁下一张 | C-E-G-C 琶音 |
| `win.wav` | 0.80 s | 三张图纸全部建成（通关） | 六音上行 + 下行收尾 |
| `fail.wav` | 0.70 s | 材料耗尽或超时（失败结算） | 四音下行 |

放置/破坏的**画面反馈**是粒子（`client/src/VoxelFx.zan`）：放置扬一圈淡尘、
破坏飞该类方块同色的碎屑，锚在世界格上（相机移动时跟着地形走）。

播放走公共包 `Game.Foundation.SfxBank`（磁盘优先 + 内嵌兜底 + 限频 +
无音频设备时静默降级），项目侧只声明名字与事件
（`client/src/VoxelSfx.zan`）。**没有声卡时静默失效，不崩不卡。**

## 四、怎么重新生成

```powershell
# 1) 生成 4 张 AI 原图（原始图落在 build/raw/，不入库）
pwsh -File client\tools\gen_images.ps1      # 需要 OPENAI_API_KEY
#    单张生成：
#    & "$HOME\.codex\skills\local-image2\scripts\image2.ps1" generate `
#        --model gpt-image-2.5 --prompt "<英文提示词>" --size 1024x1024 `
#        --quality high --output-format png --out "<绝对路径>.png" --force

# 2) 抠底 / 裁边 / 缩放 / 朝向精灵表 / 程序化贴图与底板 / 合成 WAV → 入库
python client\tools\make_assets.py

# 3) 重新编译并跑测试
pwsh -File client\tools\build.ps1
pwsh -File client\tools\test.ps1
```

`make_assets.py` 的处理链：

- **AI 原图**：RGBA 化 → 从四边洪泛抠掉纯黑底（阈值 26）→ 裁到内容边界 →
  等比塞进「显示尺寸 × 2」的画布 → 降色深（posterize，步长 8）压体积。
  `bg_sky.png` 是满幅远景，不抠底，改用调色板量化（160 色）。
- **朝向精灵表**：原图抠底 → 裁边 → 缩到 96×128 → 水平镜像一次 → 拼成
  192×128（帧 0 = 朝右，帧 1 = 朝左）。
- **方块贴图**：直接在 64×64 显示分辨率上程序化绘制等距立方体（顶面菱形 +
  左面 + 右面，三面亮度 100%/76%/55%），再 NEAREST 放大 2 倍。
- **地面贴花**：与方块贴图同一套几何（64×64 作画空间 + 同一顶面菱形），
  顶面菱形的 (u,v) 方格坐标仿射映射到画布，再 NEAREST 放大 2 倍。
- **UI 底板 / 投影**：圆角渐变 + 描边 + 铆钉；投影是径向渐隐的软椭圆。
- **音效**：`wave` 模块写 22050 Hz / 16 bit / 单声道 WAV。

> **原始生成图不入库**：`build/` 已被 `.gitignore` 忽略，`build/raw/` 下的
> 1024² 原图与脚本只作本地缓存，不进版本库；体检脚本也只统计入库资产。
